## 3. 生成数据：严格复用00031条件

读取 `config.json` 和 `IMPLEMENTATION.json`，这些是机器可核对的固定配置。

| 项目 | 固定条件 |
|---|---|
| 角色／特征 | G1，29个单轴受限关节；float32 `[N,10,59]` |
| 时间 | 50Hz，帧间隔0.02秒，旧帧到末帧，十帧跨度0.18秒 |
| GSI | 原 `load_denoiser`、`_maybe_compile`、`_ddpm_sample`；LaFAN run先验、DDPM50步、每批1024 |
| 数值 | 完整十帧有限值、旋转可恢复，原00031数值条件 |
| 关节 | 完整十帧29个模型限位，容差`1e-5 rad`，自由根节点不纳入 |
| 允许修正 | 整条最大超限≤1°才尝试，>1°整条淘汰；容差内整条不改 |
| 修正方式 | 完整十帧越界角截到硬限位；末端特征加`FK(修正后)-FK(原始)`；根状态不改 |
| 修正后检查 | 全十帧关节、自穿透、地面条件重新检查 |
| 自穿透 | 原469对，排除同一身体、直接父子身体、明确四对；重叠容差0mm，恰好接触通过 |
| 地面 | 完整十帧全部碰撞体最大穿地≤19.72mm；不限制离地高度 |
| 其他 | 不新增速度／加速度／存活阈值，不修正高度，不按动作类别重采样 |

脚本只用同一任务的 `Scene` 编译私有CPU模型，核对其几何和关节manifest与**实际00031训练记录完全一致**。没有GPU环境、实时策略或物理步进；静态筛选不受PPO并行环境数影响。原00031的摩擦／推扰等训练随机化不用于生成额外轨迹，也不改写其场景配置。

冻结先验：`datasets/pretrain_ckpt/pretrained_lafan_run.pt`。

SHA256：`74787104ff124191136eeed2268f79448da3ac2e30e710d42aebfc5a60e58cb3`。

数据计数规则：

1. 每批生成1024条；沿用00031筛选与修正函数，对合格的**最终版本**去重。
2. 去重单位为完整`10×59`连续小端float32字节，使用SHA256；不取整、不近似合并，保留首次出现者。修正后相同的片段只计一次。
3. 按生成批次／批内行号顺序接收，直到**100,000条唯一合格片段**。不只生成十万条原始候选，也不为凑数复制片段。
4. 最后一批多出的合格条目不保存；记录重复数、配额外数量与筛选汇总。失败候选、重复和配额外原始数组只驻留内存，用完即释放，无需落盘。
5. 应急上限约为目标数量100倍的原始生成量；达到后非零退出，不放宽阈值、不填零、不使用未筛选或旧策略缓存。
6. 保存后重载，完整复检全部十万条：不再次修正也能通过严格检查；重新计算全部片段哈希及唯一数量。
7. 数据在离线训练集内汇总。**十万条是离线数据规模，不修改SMP原4096条缓存容量。**本轮不运行FIFO刷新或重置采样。

## 4. 共用输入归一化

- 只用最终十万条数据，沿样本和时间两个轴，以float64计算59通道的均值、总体标准差`ddof=0`。
- `std < 1e-6`的通道缩放因子设为1，其余使用实际std。保留全部59通道；不额外裁剪数值。
- `(x-mean)/scale`后转float32，检查有限值。
- 两版共用同一个冻结归一化参数文件及数据SHA；不使用Humanoid参数、不逐片段标准化、不复用扩散先验的分位数缩放。
- 标准化数组仅驻留内存，不保存第二份全量数据。

## 5. 两版训练与聚类

按 **64维→320维** 串行运行，使用同一份已核验的数据；分别重新初始化并训练编码器。

| 参数 | 两版共同设置 |
|---|---|
| 输入 | 完整`[100000,10,59]`，不展平 |
| 输出维度 | 分别64、320 |
| hidden_dims／depth | 64／10，官方默认 |
| Batch size | 64 |
| epoch／n_iters | 20／None |
| 优化器／学习率 | 官方AdamW／0.001，默认权重衰减，无额外调度 |
| temporal_unit | 0 |
| 裁剪 | 官方重叠上下文裁剪，共同区域2～10帧 |
| 掩码／dropout | 官方binomial，时间点50%保留／0.1 |
| 精度 | float32，不开启AMP；关闭TF32、cuDNN benchmark |
| 种子 | 2027；各版初始化前固定，初始化后重置训练随机流 |
| 取模 | 完成20epoch后的官方参数平均编码器，不是EMA，不挑最佳epoch |
| 表示 | 完整十帧、`mask=all_true`、`encoding_window=full_series`最大池化 |
| 附加变换 | 无PCA、L2归一化、额外表示标准化 |
| K-means | 各版独立拟合16簇；k-means++，n_init=10，max_iter=300，tol=1e-4，seed=2027，lloyd |

官方源码固定为 `zhihanyue/ts2vec@b0088e14a99706c05451316dc6db8d3da9351163`，位于 `third_party/ts2vec/`，源码未改动，保留MIT许可及逐文件SHA。不安装其旧依赖清单，不重写损失、掩码、裁剪或平均模型。

**更新计数必须是每版1,562次/epoch、31,240次总更新。** 官方DataLoader使用`drop_last=True`：每epoch随机打乱后丢弃尾部32条，该32条并非固定不参与训练。不要为凑整将batch改为其他值或改变官方尾批规则。每版仅调用一次`fit(...,n_epochs=20,n_iters=None)`，不能按epoch重复创建优化器。

不同维度的参数量及计算量不同。相同种子和数据不表示两版dropout或训练过程逐位相同。
