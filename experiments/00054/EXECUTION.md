## 7. 必须核对的入池账本

- `direct_inserted + attempted == original_rows == inserted`。
- `succeeded + exhausted == attempted`。
- **`original_fallback_inserted == original_fallback_exact_verified == exhausted`**。
- `discarded == 0`，所有原始条目都保留一个代表。
- `generations == 30*exhausted + success_generation_sum`；`proposals == 32*generations`，总代数≤30×attempted。
- 成功片段的最大获选噪声RMS≤0.15、搜索与重放误差≤1e-5；直接关节修正计数全程0。

`original_fallback_exact_verified`表示入池前已经核验原始完整十帧逐字节一致的数量。任一历史帧或通道被替换都会使该批停止，不把仅末帧一致当作通过。

`GSI/qualified`仍表示原片段直接通过量；最终物理通过量为 `direct_inserted+succeeded`，当前池状态看 `NoiseRescue/pool_physical_pass_fraction`。不要求整个池全部物理合格，耗尽原片段本来就允许入池。

TensorBoard标量旧格式可能对很大的计数作float32舍入，run_info保存精确整数；完成核验沿用对应表示比较。
