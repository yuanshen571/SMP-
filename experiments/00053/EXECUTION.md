## 1. 实验定义

实验对照基线为00052提交 `204c55a2cd5ff48dff809b37218bd7bc416d1bea`；代码从00063提交 `2be2d631a7ed6cb4167fc8d7ba7f3373bb186344` 建立，复用其噪声补救实现，相对00063仅把训练种子2029改为2028、最大补救代数60改为30。全部原 `src/`、先验和依赖文件保持不变，38项源文件校验见 `BASELINE_FILES.json`。新增逻辑全部放在 `experiments/00053/`；不改变PPO、奖励或原状态恢复函数。

与00052比较时，新增的是“噪声补救＋处理后全部入池”：00052淘汰失败条目并补生成，00053按下表处理每条原始片段，补救失败也入池。

| 原始GSI片段 | 处理与入池 |
| --- | --- |
| 通过物理检测 | 原样入池 |
| 未通过物理检测，搜索中找到合格候选 | 首次合格的那一代结束后停止，选择本代固定顺序第一个合格候选入池 |
| 30代仍未合格 | **搜索候选中的历史最佳入池，仍未物理合格也入池** |

原始失败片段不参加历史最佳竞争，不回退原片段。**即使搜索候选没有优于原片段，仍选搜索候选中的最佳。** 不新增角度直接修正、动作相似度、SMP奖励或后续存活准入门槛。

数值有效性沿用基础检查，不另设数值极端情况的专项实验或替代机制。

本实验不再按物理通过率补生成。启动恰好生成4096条原始片段，逐条处理后全部入池4096条；每次刷新恰好生成1024条原始片段，处理后全部入池1024条。最终缓存允许存在物理不合格片段，这正是本实验要求，不能在收尾验收时把它们重新筛掉。

## 3. 噪声补救配置

| 参数 | 固定设置 |
| --- | --- |
| 优化器 | Sep-CMA-ES，独立条目各自维护优化器 |
| 搜索变量 | 10×59初始噪声增量，共590维 |
| 初始均值 | 零增量，从各自原始初始噪声开始 |
| 初始sigma | 0.05 |
| 每代候选 | 32 |
| 每条最多代数 | **30** |
| 每条最多提案 | 960 |
| RMS半径 | **≤0.15**，始终相对原始初始噪声 |
| 分量边界 | [-1,1] |
| 后验噪声 | 原始生成时保存的49次后验噪声，候选之间固定复用 |
| 优化器种子 | `(2028+10000+全程原始条目编号) % 2**32`，编号从0开始连续递增 |
| 评分 | 沿用小试：物理失败为10000+V，通过为V，见下文 |

`V = (max(0,关节最大越界rad-1e-5)/(π/180))² + max(0,最大穿地mm-19.72)² + 最大自重叠mm²`。

逐代保留搜索候选的历史最佳，平分保留先出现者；合格候选优先。成功即停，不为成功案例继续跑满30代。未合格案例必须完成30代，不按越界幅度跳过，不只处理踝部，不自行缩小处理条目数。

原始生成与补救解码都使用固定 **1024条** 布局，避免此前原始生成320、搜索32的跨批次差异。每32个槽位对应一个条目的32个候选，最多32条独立搜索并行；提前结束的槽位可接续下一个失败条目。独立优化器和后验噪声不混用。

超RMS提案占位解码且不参与评分/择优。空闲槽位也只是占位，不是额外有效候选。有效候选数、拒绝数、实际解码槽位数分别统计。此并行仅用于批量计算，不将不同动作放在一个优化器中竞争。

最后的获选片段按原槽位、相同1024布局做确定性重放，直接比较搜索输出和重放，误差≤1e-5，物理判定一致。搜索本身只使用每条独立NumPy RNG，不额外消耗训练的全局Torch或NumPy随机流。
