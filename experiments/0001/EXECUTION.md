## 7. 被动记录的准确时机

这部分必须读实际安装的框架源码后实现，不能只在 `env.step()` 返回后重算所有指标。

1. mjlab 1.6.0 的顺序是：物理推进 → 终止判断 → 奖励计算 → step/interval 事件 → 自动重置 → 更新目标指令 → 返回观测。返回的观测可能已经属于新回合、新目标。
2. 在原奖励函数已经计算出 `task`、`smp`、`product` 的位置，仅缓存它们的 detach 值及同一时刻目标距离/实际水平速度。返回完全相同的 product。只增加读数，不替换原奖励公式。
3. 一步中 `smp_guidance_reward()` 仍仅调用一次。不得为了日志再次调用扩散模型、推进运动历史、更新误差归一化或抽取噪声。
4. 在自动重置前取得本步终止掩码及待结束回合信息，或在 `_reset_idx` 前钩取；只保存必要的标量汇总。不能把返回后的新目标/新姿态用于上一回合统计。
5. 回合累计量在内存中跨 PPO 轮保留，直到自然结束后汇总并清零对应环境；不能每轮把未结束回合清零。框架初次 episode_length 随机偏移不代表已真实执行过这些步，实际时长用从观测起点开始的独立步数计数。
6. 保留框架默认随机起始回合长度。启动后的首个回合可能有缩短的超时窗口：单独统计这些首回合终止，下面的“完整回合”指标从一次自然重置后开始计算。默认 logger 的指标照常存在，另用清晰的自定义标签排除首回合时间偏移，不改变训练。
7. 不使用日志采样的随机数；不为了观测主动 reset、forward、抽样、额外 GPU 环境步或改变终止条件。多项失败同一步发生时失败回合只计一次。

### 8.2 有合格回合结束时写入的均值/比例

- `Episode/complete_task_return_raw_mean`：每个完整回合先累计本回合每步的纯任务奖励，再对本轮结束的完整回合等权求均值。
- `Episode/complete_training_return_mean`：同样处理，但累加原环境返回的训练奖励，包括 dt 缩放。
- `Episode/complete_length_steps_mean` 与 `Episode/complete_survival_s_mean`：完整回合实际步数均值及其除以 50 的秒数。
- `Failure/complete_rate`：完整失败数 ÷（完整失败数＋完整仅超时数），取值 0～1。
- `Failure/complete_duration_s_mean`：完整失败回合实际时长总和 ÷ 完整失败数。
- `Failure/all_ended_rate`：所有失败数 ÷ 所有结束回合数，包含启动首回合；与完整回合失败率区分命名。

没有对应分母时，跳过该均值/比例事件，同时计数和总和仍写 0；不能填 0 均值、沿用上一轮值或伪造完整 10000 个有效均值点。不写 NaN/Inf 占位。总存活时间均值按完整回合统计；失败时长均值只对失败回合统计，超时回合不混入。

失败按非 timeout 终止条件的并集判断。若同一步既失败又超时，归入失败，不归入 timeout_only。保证 `failure + timeout_only = ended`。任何外部强制重置/中断不能作为自然失败或正常超时。各终止原因可分别记诊断计数，但原因计数可重叠，不能相加当失败总数。

保留 sum 和 count 的原因：后续可从 TensorBoard 正确计算窗口内按回合加权的均值和失败率，避免把回合数不同的逐轮比例简单平均。若要报告逐轮等权均值和轮间标准差，另明确统计口径；本次没有逐回合原始文件，不得宣称能恢复任意分位数或逐回合分布。

每隔约 10 秒及正常退出时 flush/close writer。读取事件做验收时禁用采样/数量限制，兼容 scalar/tensor 两种标量编码；不能用网页平滑曲线或默认抽样后的导出代替完整事件核对。单张 L40 的 2.4576 亿训练步累计样本数建议以足够精度写入，避免 float32 大整数精度丢失。
